# ADR 0001: 하네스 스켈레톤
- 상태: 채택
- 배경: 규칙 문장만으로는 ‘Red를 봤다’는 거짓 보고를 막지 못한다.
- 선택지 A: 지침만 사용한다.
- 선택지 B: 파이썬 게이트 스크립트와 `AGENTS.md`를 사용한다.
- 선택지 C: `/goal`을 사용한다.
- 결정: B. Codex 샌드박스는 `.git`에 쓰지 못하므로 하네스 명령만 `.codex/rules/tdd.rules` 허용 규칙으로 샌드박스 밖에서 실행한다.
- 결과 — 좋은 점: 규칙 문장만으로 막을 수 없는 거짓 Red 보고를 게이트로 통제한다. 감수할 점: 파이썬 게이트 스크립트와 허용 규칙을 함께 유지한다.
- 다시 볼 때: `/goal`이 모델의 완료 판정 대신 승인 대기를 지원하거나, 샌드박스 안에서 `.git` 쓰기가 가능해질 때 재검토한다.
